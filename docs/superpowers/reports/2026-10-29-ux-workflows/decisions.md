# Решения, принятые при автономной работе

Пользователь разрешил самостоятельно выполнять работу и создавать артефакты superpowers. Порядок ниже соответствует журналу решений.

| Решение | Основание | Ограничение / цена ошибки |
| --- | --- | --- |
| Работать в отдельном managed worktree и локальной ветке; сохранить исходный аудит | Изоляция рабочего checkout | Результат нужно интегрировать отдельно; публикации нет |
| Разделить независимые области между исполнителями; коммиты делает координатор | Ускорение без конкурирующих правок общих файлов | Ошибки интеграции ловятся общими тестами и независимым ревью |
| Массовое редактирование выполняет последовательные PATCH | Имеющийся API поддерживает отдельные изменения | Общей транзакции нет; предыдущие записи сохраняются при ошибке |
| Включить типизированные формы и поиск по БД из полного аудита | Это часть предложенного объёма, даже если краткий ответ её не перечислил | Объём изменений и проверки больше первоначального краткого списка |
| Добавить необязательный порт соединения в DriverInfo | Разделить SQL-черновики разных серверов на одном хосте | Старые клиенты поле игнорируют; старые записи браузера могут не совпасть с новым ключом |
| Добавить параметризованный CONTAINS с ESCAPE '!' | Надёжный буквальный поиск при разных SQL mode MySQL | Требует новой серверной части; поиск может сканировать большие таблицы |
| Менять выбранную схему только после успешной навигации | Отказ от перехода не должен менять контекст редактора | Контекст меняется после завершения перехода |
| Сделать csvEncoding дополнительной опцией; UI экспортирует escaped, API сохраняет прежнее умолчание | Сохранить совместимость и различать NULL/пустую строку/обратный слеш | При импорте внешнего файла нужно выбрать подходящее кодирование |
| Увеличить лимит полного integration target с 10 до 30 минут на Go-пакет | Полная матрица создаёт отдельные контейнеры и достигла прежнего лимита | Настоящее зависание может обнаруживаться позже; проверки готовности контейнеров прежние |
| Для новой массовой формы требовать первичный ключ | Одинаковые строки без PK нельзя безопасно различить имеющимся API | Без PK доступны существующие одиночные действия или SQL, но новая массовая форма отключена |

Дополнительная явно описанная семантика: PostgreSQL data-only экспорт включает локальные родительские таблицы и записывает их первыми; циклы требуют режима структуры и данных. Это сохраняет восстанавливаемость данных, но файл может содержать связанные таблицы помимо выбранных.
