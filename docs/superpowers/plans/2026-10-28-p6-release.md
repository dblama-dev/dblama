# P6 local release packaging

Scope: new Dockerfile, .dockerignore, .goreleaser.yaml, release workflow, README, changelog and local release smoke script. Root owns merge and any external publication; this task publishes nothing.

## Plan

1. Verify current official GoReleaser, Actions and distroless documentation and available tool versions.
2. Add a failing packaging smoke check, then configure six static binaries (linux/darwin/windows × amd64/arm64), archive/checksum generation and embedded SPA ordering.
3. Add a nonroot distroless multi-stage container and a draft-release/manual-snapshot workflow.
4. Document configuration, build/release use and all current database operational limits without inventing a license.
5. Validate GoReleaser configuration/snapshot and run local binary/HTTP plus Docker smoke checks.

## Decisions and sources

- GoReleaser v2.19.0, checksum-verified official local tool download. v2 schema, plural archive formats, module build dir `server`, frontend global hooks.
- Go compiler 1.26.8 follows server/go.mod; Node 24 follows supported project runtime. Latest official action releases verified: checkout v7.0.1, setup-node v7.1.0, setup-go v7.0.0, upload-artifact v7.0.2, goreleaser-action v7.3.0. Workflow uses v7 majors and pins GoReleaser tool v2.19.0.
- Distroless static-debian13:nonroot supports amd64/arm64 and supplies certificates/timezone data without a shell. Final user fixed to 65532:65532; Docker smoke uses read-only root filesystem.
- Release archives package README and changelog; no LICENSE invented. Workflow supports manual local snapshots and operator-pushed tags producing draft GitHub releases and nonroot multiarch GHCR images. No publishing command is run locally. The user checkout remote is left untouched; local GoReleaser validation uses a disposable fixture clone with an explicitly fake test-only GitHub remote.
- Official docs consulted: https://goreleaser.com/customization/builds/builders/go/ ; https://goreleaser.com/customization/general/hooks/ ; https://goreleaser.com/customization/package/archives/ ; https://github.com/goreleaser/goreleaser-action ; https://github.com/GoogleContainerTools/distroless .

- `PATH=/tmp/db-manager-release-tools:$PATH GOCACHE=/tmp/db-manager-audit-go-cache ./scripts/check-release.sh --docker` in fixture: PASS. Six Linux/macOS/Windows × amd64/arm64 archives, SHA-256 checksums and executable formats verified. Host binary HTTP smoke confirms SPA HTML, bundled JS, three drivers, unauthenticated session rejection and SPA deep-link fallback.
- Every tar.gz/zip archive independently inspected: README.md, CHANGELOG.md and platform executable present. `file` confirms Linux amd64 is statically linked.

- Independent review reproduced a BuildKit architecture error: defaulting `ARG TARGETARCH=amd64` overrode the automatic arm64 value. A `linux/arm64` Docker build exported the binary and verified ELF machine 183 (AArch64); the smoke script repeats this check.

- `actionlint .github/workflows/release.yml`: PASS. `bash -n scripts/check-release.sh`: PASS. Official current Docker actions verified: setup-qemu v4, setup-buildx v4, login v4, metadata v6, build-push v7.
- Publishing capability preserved: operator-pushed numeric semantic-version tags run the test matrix, create draft GitHub releases and publish amd64/arm64 GHCR images. Manual workflow dispatch builds snapshot artifacts and smoke-tests Docker without a registry push. No local release or image was published.
