# Changelog

## Unreleased — v0.1.0

- Single Go binary with an embedded Vue interface and Russian/English translations.
- MySQL, MariaDB and PostgreSQL connections with expiring in-memory sessions.
- Table/data browsing, structured filtering, pagination, row editing and bulk operations.
- Table structure, indexes, foreign keys, database operations and table transfer controls.
- SQL console with selection execution, history, cancellation, EXPLAIN and result grids.
- SQL/CSV/TSV import and export with progress and gzip SQL input/output.
- Views, triggers, functions/procedures, procedure calls with OUT/INOUT results, MySQL events and partitions, PostgreSQL schemas and sequences.
- MySQL/MariaDB account, resource-limit and privilege management; server process/status/variable monitoring and process termination.
- Cross-platform release archives for Linux, macOS and Windows on amd64 and arm64, checksums and a nonroot distroless Docker build.

The first public release has not been published. Operational limits and database-specific behavior are documented in README.md.
